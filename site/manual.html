01 什么是 DeepSeek Harness —— 你的机器人在哪

如果你用过 ChatGPT、DeepSeek 或各种 AI 助手，可以把它们想象成一台机器人：它会思考、会执行任务，但「裸机」状态下的它，能力是固定的 —— 就像一台没有装甲、没有武器、没有雷达的机甲骨架。

DeepSeek Harness（简称 dsh）就是 DeepSeek 官方开源的一副机器人底盘（agent harness）：骨架、神经、供能、工具接口全部就绪，官方口号只有一句话 —— Everything is a Plugin（一切皆插件）。你想让它会什么，就给它装什么：

  • 装「视觉装甲」→ 机器人能看图、能识别界面；
  • 装「记忆装甲」→ 机器人跨会话记住你、随时检索过去；
  • 装「通讯装甲」→ 任务一完成，飞书微信立刻向你汇报。
官方事实小抄：DeepSeek Harness 由 DeepSeek AI 开发、开源（MIT 协议），底层由 Cordis 框架驱动（论文《A Programming Paradigm for Spatiotemporal Composability》）；当前处于开发者预览（developer preview）阶段，迭代很快，可能有兼容性破坏的更新。

而 DS安甲网（ds.ajw.cn），就是这台机器人的装甲超市与整备机库：每天把 GitHub 上 DeepSeek Harness 生态的插件（装甲）搜罗上架、按你的需求分类陈列、附上一键复制的组装指令 —— 你负责挑选，粘贴给 Agent 就能装上。

02 四个核心概念：本体、装甲、技能、整备

Agent · 机器人本体

会思考、会调用工具、会执行任务的 AI 智能体 —— 你的机器人。DSH 就是为它提供身体的框架。

Plugin · 功能装甲

给机器人加装的能力模块。官方原则「一切皆插件」：界面、工具、模型桥接……全是插件。本站货架上的主要商品。

Skill · 技能芯片

教机器人「怎么做一件事」的说明书式技能，也是生态里活跃的开源品类 —— 货架上有专门的一格。

Profile · 整备方案

一组装甲的成套搭配（bundle）。像机甲整备方案一样，一次装上一整套，重启后整机状态焕然一新。

一句话总结：DSH 提供身体，插件提供装甲，你负责挑选和装配 —— 机器人强不强，看你给它装了什么。

03 把机器人跑起来：官方安装手册

方式一 · 一条命令启动（官方推荐）

先安装 Node.js，然后在终端执行：

npx @deepseek-ai/dsh web

命令会启动 Web UI，默认地址 http://127.0.0.1:3080 —— 机器人在你本机睁开眼睛。

方式二 · 从源码整机自造

git clone https://github.com/deepseek-ai/deepseek-harness.git && cd deepseek-harness && pnpm install && pnpm run build && pnpm dsh web
注意：项目处于开发者预览阶段，官方明确提示「THERE WILL BE COMPATIBILITY-BREAKING CHANGES（会有破坏兼容性的变更）」—— 日常使用建议以官方最新文档为准，升级前先看更新说明。

04 装甲是怎么装上去的

DSH 的插件安装命令直通包管理器，在货架上看到任何一件装甲，都可以这样装：

dsh plugin add "github:owner/repo"
  • dsh plugin 会把安装操作转交给包管理器，支持 npm 包、GitHub 仓库、本地路径等来源；
  • 安装/更新后重启 dsh 生效；
  • 管理面板：Settings → Plugins，像机库控制台一样统一查看与维护；
  • 官方建议插件仓库打上 dsh-plugin 话题标签，方便被社区发现（本站每天都会扫这个话题）。

想和社区交流？官方有 GitHub Discussions 与 Discord 社区，反馈问题、晒你的整机配置都行。

05 DS安甲网使用说明：检索与装配三步走

  1. ①
    逛货架 · 检索装甲

    在首页顶部搜索框输入需求关键词 —— 支持项目名、简介、标签、作者检索（如「vision」「TUI」「皮肤」「记忆」）；再用分类货架、语言筛选缩小范围，按星标、最近更新、最新收录排序。

  2. ②
    看中文简介 · 复制组装指令

    每件装甲都配有中文介绍（外文介绍已自动翻译，悬停可看原文）、星标与更新时间等参数读数，卡片底部就是它的组装指令，点复制按钮一键拷贝。

  3. ③
    粘贴给 Agent · 完成装配

    把指令粘贴给终端或你的 Agent，插件就装好了；跳转 GitHub 仓库还能查看文档、Issue 与更新记录。

机库每日补给：数据每天 10:30（UTC+8）自动抓取更新，保留最近 30 天快照 —— 带「新增」角标的装甲是昨天还没有的新货。
