新手机师手册：把装甲装进你的 DSH

为你的 DeepSeek Harness 机器人 安装上所需功能的装甲吧

这是安甲网的手册页，刻意做成明亮的文档模式——控制台是给「扫货」用的，手册是给「读完装好」用的。全文九章，读完大约六分钟。

本手册依据 deepseek-ai/deepseek-harness 官方项目介绍编写 · 3 分钟读懂 · 货架数据每日更新

01这台机器是什么

如果你用过 ChatGPT、DeepSeek 或各种 AI 助手，可以把它们想象成一台机器人：它会思考、会执行任务，但「裸机」状态下的它，能力是固定的 —— 就像一台没有装甲、没有武器、没有雷达的机甲骨架。

DeepSeek Harness（简称 dsh）就是 DeepSeek 官方开源的一副机器人底盘（agent harness）：骨架、神经、供能、工具接口全部就绪，官方口号只有一句话 —— Everything is a Plugin（一切皆插件）。你想让它会什么，就给它装什么：装「视觉装甲」它就能看图，装「记忆装甲」它就能跨会话记住你，装「通讯装甲」任务一完成飞书微信立刻向你汇报。

而 DS安甲网（ds.ajw.cn），就是这台机器人的装甲超市与整备机库：每天把 GitHub 上 DeepSeek Harness 生态的插件搜罗上架、按你的需求分类陈列、附上一键复制的组装指令 —— 你负责挑选，粘贴给 Agent 就能装上。

  • 收录范围关键词检索 + awesome 列表巡检 + 精选种子三条腿走路。同一个仓库被多条腿抓到只算一次。
  • 去重规则fork 一律剔除、已归档剔除、README 与 DSH 无关剔除、相关度低于阈值 5 剔除。
  • 分类15 类机甲分类，覆盖插件在 DSH 里可能待着的所有位置。分类是关键词规则 + awesome 章节映射的组合，不是模型瞎猜。
  • 时间每天 10:30（UTC+8）抓一次，快照保留 30 天。新入库的会在卡片上挂一个「今日新增」或「30 天新增」角标。
一个提醒：星标高不等于适合你。先看分类和语言，再看最近更新时间——超过半年没推的插件，接口大概率已经漂了。

02四个核心概念

本体、装甲、技能、整备 —— 这四个词覆盖了官方文档里最常用的说法，看懂它们就能看懂整个生态。

A

Agent · 机器人本体

会思考、会调用工具、会执行任务的 AI 智能体 —— 你的机器人。DSH 就是为它提供身体的框架。

P

Plugin · 功能装甲

给机器人加装的能力模块。官方原则「一切皆插件」：界面、工具、模型桥接……全是插件。本站货架上的主要商品。

S

Skill · 技能芯片

教机器人「怎么做一件事」的说明书式技能，也是生态里活跃的开源品类 —— 货架上有专门的一格。

B

Bundle · 整备方案

一组装甲的成套搭配。像机甲整备方案一样，一次装上一整套，重启后整机状态焕然一新。

官方事实小抄：DeepSeek Harness 由 DeepSeek AI 开发、开源，底层由 Cordis 框架驱动；当前处于开发者预览阶段，迭代很快，可能有兼容性破坏的更新。

03把机器人跑起来

方式一 · 一条命令启动（官方推荐）

先安装 Node.js，然后在终端执行：

$npx @deepseek-ai/dsh web

命令会启动 Web UI，默认地址 http://127.0.0.1:3080 —— 机器人在你本机睁开眼睛。

方式二 · 从源码整机自造

$git clone https://github.com/deepseek-ai/deepseek-harness.git && cd deepseek-harness && pnpm install && pnpm run build && pnpm dsh web
注意：项目处于开发者预览阶段，官方明确提示「THERE WILL BE COMPATIBILITY-BREAKING CHANGES（会有破坏兼容性的变更）」—— 日常使用建议以官方最新文档为准，升级前先看更新说明。

04装甲是怎么装上去的

DSH 的插件安装命令直通包管理器，在货架上看到任何一件装甲，都可以这样装：

$dsh plugin add "github:owner/repo"
  • 包管理器负责解析dsh plugin 会把安装操作转交给包管理器，支持 npm 包、GitHub 仓库、本地路径等来源。
  • 重启才生效安装或更新后重启 dsh 生效。
  • 统一管理管理面板在 Settings → Plugins，像机库控制台一样统一查看与维护。
  • 打标签能被更快收录官方建议插件仓库打上 dsh-plugin 话题标签，这是本站 9 组关键词里命中效率最高的一组 —— 本站每天都会扫这个话题。

想和社区交流？官方有 GitHub Discussions 与 Discord 社区，反馈问题、晒你的整机配置都行。

05检索与装配三步走

  1. 1
    逛机库 · 检索装甲

    在机库页顶部搜索框输入关键词即可模糊检索：项目名、分类名、语言、标签四路同时命中，命中处会高亮。再用分类芯片、语言下拉缩小范围，按相关度 / 星标数 / 最近更新 / 30 天新增排序，或勾选「仅看 30 天新增」只看新货。

  2. 2
    看读数 · 复制组装指令

    每件装甲都配有中文介绍（外文介绍已自动翻译，悬停可看原文）、星标 / Fork / 相关度 / 语言 / 许可证 / 最近更新读数，卡片底部就是它的组装指令，点「复制」一键拷贝。

  3. 3
    看详情 · 粘贴给 Agent

    点「查看详情」可以切换国内源 / 海外源、看清全量元数据与命中来源。命令粘贴给终端或你的 Agent，插件就装好了；详情页的 GitHub 链接能继续查看文档、Issue 与更新记录。

机库每日补给：数据每天 10:30（UTC+8）自动抓取更新，保留最近 30 天快照 —— 带「今日新增」角标的装甲是昨天还没有的新货。

07三条安装路径与国内加速

每张卡片默认给你一条最合适的命令，但三种方式你随时可以换。详情页的「下载源」开关能切换国内源 / 海外源。

  • dsh plugin add · 最省事由 DSH 自己解析依赖、注册、写入配置。生态里的首选，能交给 Agent 执行的也是这一条。
  • git clone … · 要改源码时用拿到完整仓库，可以直接打 patch。国内源会把域名改写成经 ghfast.top 镜像的地址。
  • npx @deepseek-ai/dsh web · 启动机器人本体不是装插件，是把官方运行时跑起来。机库里「原厂核心」那一格就是它。

国内源改写规则：只替换下载域名，不改变命令语义。要给整台机器配一次镜像，跑下面这条就够了 —— 它写进 ~/.gitconfig，之后所有 git clone 与 dsh plugin add 都自动走镜像。

国内加速一键配置 配一次 · 全站安装命令自动经 ghfast.top 镜像拉取
$git config --global url."https://ghfast.top/https://github.com/".insteadOf "https://github.com/"
想回退怎么办：删掉 ~/.gitconfig 里那条 insteadOf 即可，或者在机库详情页把「下载源」切到「海外源」再执行命令。

08机师社群与收录流程

安甲网背后是几个频道。这里既是求助的地方，也是提交插件的地方 —— 收录规则、分类口径、关键词巡检计划都公开讨论。当前已开通 — 个频道，频道状态由 community-config.js 驱动。

收录流程

  • 提交在 Discussions 开一个收录请求，或让群友直接发 PR 到 awesome 索引仓库。
  • 入队每天 10:30（UTC+8）的巡检会把它抓进候选池，fork 与归档在这一步就被剔掉。
  • 评分自动译中 + 相关度评分。低于阈值 5 的会被挡在门外，5–8 分的需要人工看一眼。
  • 分类人工确认机甲分类。这一步不做的话，搜索和筛选会失灵，所以宁可慢一天。
  • 上架进入机库快照，30 天后如果没有更新会淡出「30 天新增」角标。

维护节奏

  • 每日 10:309 组关键词 + awesome 列表巡检，生成快照。
  • 每周一清理低相关条目，必要时下调阈值。
  • 每季度公开一次去重数据：剔了多少 fork、多少归档、多少低相关。
本站只做索引。我们不托管任何插件代码，也不替插件做安全背书。装之前请自己看一眼它要什么权限。

09装不上怎么办 · 附录

  • 命令跑了没反应先确认走的是哪条路径。只想装不想改代码就用 dsh plugin add；需要打 patch 才用 git clone。装完记得重启 dsh。
  • 拉取超时八成是源的问题。在详情页把「下载源」切到国内源，命令会立刻改写；或者跑一次上面那条 insteadOf 全局配置。
  • 插件要权限护盾类插件（沙箱、出网、审计）会申请较高权限。装之前看一眼详情页的元数据面板，它会写明这个仓库的关键词命中来源与分类释义。
  • 仓库没出现在货架上可能是 fork、已归档、相关度低于阈值 5，或者需要组织访问权限（公开接口 404）。打上 dsh-plugin 话题标签能显著提高收录速度。
