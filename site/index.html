关于 DS安甲网

数据从哪里来

每天通过 GitHub 官方搜索接口，围绕 deepseek-harness、topic:dsh-plugin、dsh plugin、deepseek skill 等关键词聚合仓库，并融合 awesome-deepseek-harness 等精选列表，按相关度评分、去重后上架。所有外文项目介绍均已自动翻译为中文，鼠标悬停简介可查看原文。

按需求逛货架

分类以「用户需求」为纲：官方核心、界面与体验、上下文与记忆、输入与编辑、浏览器与远程、模型与推理、通知与渠道、趣味与生活、基建与开发……想解决什么问题，就逛什么货架。每张卡片都带一键复制的安装命令，粘贴给 Agent 即可装好插件。

每日更新

抓取任务每天 10:30（UTC+8）自动运行，数据快照存留最近 30 天，「新增」角标表示该项目昨天还没有上架。

发现好项目？

本站本身也是开源的。想把你的 DSH 插件摆上货架，欢迎提交 Issue 或 PR —— 精选种子会第一时间收录。
